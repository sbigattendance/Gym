              Morpho Device Setup Instructions
            

            
How to configure your physical Morpho MSO 1300 E2/E3 scanner

          


          

            

              
1

              

                
Install Morpho RD Service Driver

                

                  Download and install the official Morpho RD Service (or MorphoSmart USB Driver) package for Windows or Linux.
                

              

            


            

              
2

              

                
Verify Windows Service is Running

                

                  Press Win + R, type services.msc, locate Morpho RD Service, and confirm its status is Running.
                

              

            


            

              
3

              

                
Browser Localhost Security Permission

                

                  If using Google Chrome or Edge, open chrome://flags/#allow-insecure-localhost and set it to Enabled, then restart browser.
                

              

            


            

              
4

              

                
Simulation Mode for Offline Testing

                

                  If the scanner is not currently plugged in or you are demonstrating the workflow, toggle Simulation Mode in the top header to simulate realistic captures, templates, and 1:N biometric matching.
